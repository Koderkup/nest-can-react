# Support

Please use the right channel for the kind of help you need:

- Read the [documentation](docs/README.md) and [README](README.md) first.
- Search [existing issues](https://github.com/acefolioDev/nest-can-react/issues) for known problems and workarounds.
- Open a [bug report](https://github.com/acefolioDev/nest-can-react/issues/new?template=bug_report.yml) when you can provide a reproducible problem.
- Open a [feature request](https://github.com/acefolioDev/nest-can-react/issues/new?template=feature_request.yml) for a proposed capability.
- Ask usage questions in a GitHub issue only when the documentation and existing issues do not answer them.

When asking for help, include the package version, Node.js version, Nest adapter, operating system, relevant configuration, and a minimal reproduction. Never include credentials, tokens, private URLs, or other sensitive information.

Security vulnerabilities must be reported privately as described in [SECURITY.md](SECURITY.md).
